
:default:

  gitkp SUBCOMMAND [OPTIONS]

  Utility to mark the initial repository structure with .gitkeep files,
  understanding the .gitignore by itself.

  Subcommands:
   run        create the .gitkeep files (default)
   dry-run    show what would be created, without touching anything
   undo       remove the .gitkeep files that run created
   help       show help (of a subcommand if given)

  Options:
   -c, --commit [MESSAGE]   commit the created .gitkeep files (message optional)
   --force-root PATH        force a .gitkeep in PATH root (repeatable)

  Run 'gitkp help <subcommand>' for details of a specific subcommand.
:_default:

:run:

  Usage: gitkp run [-c [MESSAGE]] [--force-root PATH ...]
  Create the .gitkeep files in every leaf directory (no subdirectories),
  respecting the .gitignore.

  Options:
   -c, --commit [MESSAGE]   commit the created .gitkeep files. The message is
                            optional: default message if none given.
   --force-root PATH        only one .gitkeep in PATH root (dynamic/ignored
                            interior). Repeatable.
  Example:
   gitkp run --force-root var
   gitkp run -c "init: add .gitkeep"
:_run:

:dry-run:

  Usage: gitkp dry-run [-c [MESSAGE]] [--force-root PATH ...]
  Show what would be created, without touching anything.
:_dry-run:

:undo:

  Usage: gitkp undo
  Remove the .gitkeep files created by this tool.

  If the .gitkeep files were committed with run -c and the last commit
  contains only .gitkeep files, the commit is undone first (git reset)
  and then the files are removed.
  If there are later commits or the files are part of older history,
  they are skipped (the tool does not rewrite history).
:_undo:

:help:

  Usage: gitkp help
  Show this help.
:_help:
